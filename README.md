# PRTS Terminal - Academic Task Manager

Aplikasi web pengelolaan daftar tugas kuliah menggunakan **TypeScript** dan **Vite** yang terintegrasi pada website pribadi (`ark4na.my.id`) untuk Tugas Pertemuan 6 Pengembangan Aplikasi Web.

## Fitur Utama
- Menampilkan, menambahkan, mengedit, dan menghapus daftar tugas kuliah.
- Mengubah dan memfilter status tugas (`Belum Selesai` / `Selesai`).
- Implementasi TypeScript: primitive types, array, interface, type alias, union type, dan generics.
- Konfigurasi aplikasi non-rahasia menggunakan `.env` dan `.env.example`.

## Menjalankan Secara Lokal

    npm install
    cp .env.example .env
    npm run dev

## Build Produksi

    npm run build
